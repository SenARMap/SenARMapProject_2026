# キャンパスマップARプロジェクト：データ構造設計仕様書

## 1. 座標系定義 (Coordinate System)
学内の位置関係を正確に表現するため、10号館は以下の基準で座標を管理します。

* **原点 (0, 0, 0)**: 正面エントランス（点ID: 1）を基準とする。
* **単位**: メートル（小数点第1位まで保持、10cm単位の精度）。
* **軸の向き**:
    * **X軸**: 山を登る方向（斜面の上方）をプラスとする。
    * **Y軸**: X軸のプラス方向に対して右向きをプラスとする。
    * **Z軸**: 高さ（垂直方向）をプラスとする。

---

## 2. 点データ仕様 (points.csv)
ノード（地点）を定義します。入口、階段前、分岐点などに配置します。

| カラム名 | データ型 | 説明 | 備考 |
| :--- | :--- | :--- | :--- |
| `id` | Integer | 点の一意な識別子 | 1: 正面エントランス |
| `x` | Float | X座標 (10cm単位) | 山を登る方向 |
| `y` | Float | Y座標 (10cm単位) | 右向き |
| `z` | Float | Z座標 (10cm単位) | 高さ |
| `building` | String | 建物名 | 例: `building_10`, `building_ikuta` (外は `0`) |
| `floor` | Integer | 階数 | 数値のみ (例: 1, 2) |
| `type` | Integer | 地点の属性 | 1: 通常, 2: 出入り口(外と接続) |

---

## 3. 線データ仕様 (lines.csv)
エッジ（経路）を定義します。点と点を結び、教室情報や移動コストを保持します。

| カラム名 | データ型 | 説明 | 備考 |
| :--- | :--- | :--- | :--- |
| `id` | Integer | 線の一意な識別子 | |
| `name` | String | 表示名（教室名等） | 複数ある場合は `;` 区切り (例: `101A;101B`) |
| `from` | Integer | 開始地点の点ID | `points.csv` の `id` に対応 |
| `to` | Integer | 終了地点の点ID | `points.csv` の `id` に対応 |
| `building` | String | 建物名 | 点データに準拠 |
| `floor` | Integer | 階数 | 点データに準拠 |
| `length` | Float | 物理的な距離 | メートル単位 |
| `weight` | Float | 経路探索用の重み | 1: 平坦, 5: 階段, 任意: 坂道 |
| `type` | Integer | 経路の種別 | 1: 道, 2: 階段, 3: エスカレータ, 4: EV |

---

## 4. 運用ルール・仕様
* **建物名 (`building`)**: 原則としてASCII文字（英数字・アンダースコア）を使用。
* **重み (`weight`)**: ナビゲーション時の優先度。階段を避ける設定などの計算に使用。
* **エレベーター (`type: 4`)**: アプリ側で「エレベーターを使用するか」を選択可能にするためのフラグとして扱う。
