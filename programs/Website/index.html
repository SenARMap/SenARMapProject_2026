IKU NAVI

AR Campus Navigation

大学構内を対象にした AR 対応ナビゲーション Web アプリ。
スマホ一つで、迷わず目的地へ。

アプリを試す GitHub

主要機能

スマホで、迷わない。

屋外と屋内を自動で切り替えるハイブリッドマップと、実写 AR ナビで目的地まで案内します。

ハイブリッド・マップ

屋外では Google Maps、屋内では SVG フロアマップへ自動切り替え。シームレスに構内をナビゲートします。

ステップ・ナビゲーション

矢印ボタンで 1 ステップずつ進む経路案内。実写 AR 画像・青ハイライト・赤矢印が連動して誘導します。

ダイクストラ経路探索

グラフ理論に基づく Dijkstra 法で最短経路を算出。エレベーターの有無も考慮した経路選択が可能です。

GPS 連動

navigator.geolocation で現在地を取得し、最も近い屋外ノードから経路探索を自動で開始します。

バリアフリー対応

検索時にエレベーター使用の有無を選択可能。誰もが快適に移動できるインクルーシブな設計です。
